# IRCI - Repositorio Unificado

Repositorio que centraliza y unifica todos los trabajos prácticos, implementaciones y ejercicios de la materia.

## Contenido

Este repositorio se estructura en las siguientes carpetas:

- **[instrucciones-procesador/](./instrucciones-procesador)**: Casos de prueba y documentación detallada de la ejecución de instrucciones aritméticas, lógicas y de control del procesador (ADDI, ADD, SUB, MUL, saltos, etc.).
- **[intrucciones-cpu-c/](./intrucciones-cpu-c)**: Implementación y simulación de la CPU e instrucciones en lenguaje C (hola.c).
- **[Branch-Zero/](./Branch-Zero)**: Documentación y diseño en simulación del circuito de detección y salto condicional Branch Zero (BRZ) y Zero Flag (Zero Flag.cv).
- **[Trabajo-BCMS/](./Trabajo-BCMS)**: Proyecto y diseño del juego Arkanoid, historia, mecánicas y assets gráficos/sprites.
- **[pintar-assembly/](./pintar-assembly)**: Programa interactivo en código ensamblador (pintar.rtm) que utiliza MMIO para capturar comandos del teclado (WASD, Enter, Backspace) y manipular el cursor para pintar o borrar en pantalla.
